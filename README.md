# 🕌 مواقيت الصلاة — مسجد السنة، المحمدية (معسكر)

> [!TIP]
> **🌐 الموقع مباشر الآن:** [https://steverlaabs.github.io/mawaqit/](https://steverlaabs.github.io/mawaqit/)

[![الموقع مباشر](https://img.shields.io/website?url=https%3A%2F%2Fsteverlaabs.github.io%2Fmawaqit%2F&label=%D8%A7%D9%84%D9%85%D9%88%D9%82%D8%B9&style=for-the-badge)](https://steverlaabs.github.io/mawaqit/)

موقع احترافي لعرض مواقيت الصلاة لمسجد السنة بمدينة المحمدية، ولاية معسكر، الجزائر.

✅ **يعمل بالكامل دون خادم** — حساب الأوقات يتم داخل متصفح الزائر بمكتبة [adhan](https://github.com/batoulapps/adhan-js) حسب إحداثيات المسجد، لذا يمكن استضافته مجاناً على **GitHub Pages** ويبقى دقيقاً حتى دون إنترنت بعد أول زيارة.

## ✨ الميزات

- 🕐 مواقيت اليوم الستة + عدّاد تنازلي حي للصلاة القادمة
- 🌙 منتصف الليل والثلث الأخير (قيام الليل)
- 📅 جدول مواقيت الشهر كاملاً مع التنقل بين الأشهر ونسخ أي يوم بضغطة
- 🕌 وقت الجمعة يظهر تلقائياً يوم الجمعة (12:45 م)
- 🔊 **أذان صوتي** عند دخول وقت كل صلاة (بعد تفعيله بضغطة واحدة)
- 📢 تنبيه **«الله أكبر»** قبل الأذان بـ 5 دقائق للاستعداد
- 📿 **أذكار الصباح والمساء والنوم وبعد الصلاة** مع عدّاد لكل ذكر
- 🤲 **استغفار دائم** — شريط يتنقل بين عبارات الاستغفار باستمرار
- 🖥️ **وضع سطح المكتب** — ساعة حية في الرأس وتخطيط موسّع للشاشات الكبيرة (≥1024px)
- 📺 **وضع التلفاز** — شاشة عرض عملاقة بضغطة واحدة (زر 📺 أو `?tv=1`) تملأ الشاشة بالكامل بدون تمرير، مع زر ملء شاشة ⛶ وزر خروج
- 📱 تصميم متجاوب يعمل على الهاتف والحاسوب، بالعربية RTL
- ♿ متوافق مع قارئات الشاشة ووضع الحركة المقلّصة

## ⚙️ الإعدادات

كل ما تحتاج تعديله في ملف واحد: [`js/config.js`](js/config.js)

| الإعداد | الوصف |
|---|---|
| `latitude` / `longitude` | إحداثيات المسجد (الافتراضي: من OpenStreetMap) |
| `jumua.time` | وقت صلاة الجمعة |
| `madhab` | مذهب العصر (`maliki` — قياس ظل شيء، أو `hanafi`) |
| `calculationMethod` | منهج الحساب (الافتراضي: رابطة العالم الإسلامي) |
| `adhan.file` / `adhan.volume` | ملف صوت الأذان ومستوى الصوت |
| `takbir.enabled` / `takbir.beforeMinutes` | تنبيه «الله أكبر» قبل الأذان |

## 🖥️ العرض على تلفاز المسجد

1. افتح الرابط `?tv=1` على متصفح التلفاز (أو اضغط زر 📺 في أسفل الصفحة)
2. اضغط زر **⛶** لملء الشاشة
3. فعّل الصوت بضغطة واحدة ليشتغل الأذان
4. في إعدادات التلفاز: أوقف حافظة الشاشة/السكون ليعمل العرض باستمرار

> 💡 الطريقة الأثبت: حاسوب موصول بالتلفاز بكابل HDMI، أو جهاز Android TV Box مع متصفح Chrome.

## 📤 النشر على GitHub Pages

```bash
git init
git add .
git commit -m "مواقيت الصلاة — مسجد السنة المحمدية"
gh repo create mawaqit --public --source=. --push
gh api repos/{owner}/mawaqit/pages -X POST -f build_type=legacy -f source='{"branch":"main","path":"/"}'
```

أو من واجهة GitHub: **Settings → Pages → Source: Deploy from a branch → main / root**.

## ℹ️ معلومات تقنية

- **الإحداثيات**: 35.589562° شمالاً، 0.074046° شرقاً (Mosquée de la Sunna, Rue Pasteur — OpenStreetMap)
- **المنطقة الزمنية**: Africa/Algiers (غرينتش+1، بدون توقيت صيفي)
- **المنهج**: رابطة العالم الإسلامي، العصر على القياس (المذهب المالكي)
- **التاريخ الهجري**: تقويم أم القرى عبر `Intl`
- **الأذان**: ملف صوتي محلي (`assets/adhan.mp3`) يُطلق محلياً بعد تفعيل المستخدم

> ⚠️ الأوقات تقريبية للتذكير؛ اعتمد أذان المسجد الرسمي.
